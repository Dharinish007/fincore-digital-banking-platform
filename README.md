# Fincore Digital Banking Platform

This repository contains backend modules for the FinCore banking platform.

## Available projects
- `account-creation`: Spring Boot service for account creation
- `Transaction Automicity`: Spring Boot service for transaction management

## Notes
- Both modules use Java 18 and Maven.
- Run builds with the included Maven wrapper:
  - `cd account-creation && .\mvnw.cmd compile`
  - `cd "Transaction Automicity" && .\mvnw.cmd compile`

## Frontend
No frontend project is currently configured in this repository.
A placeholder `npm run dev` command has been added to `package.json`.
