# Account Service

## Project
FinCore Digital Banking Management Platform

## Module
Account Creation Backend

## Description
This module is responsible for creating new bank accounts in the FinCore Digital Banking Platform. It is developed using Spring Boot following a layered architecture.

## Tech Stack
- Java
- Spring Boot
- Spring Data JPA
- Maven
- MySQL (Database integration in progress)

## Project Structure

```
account-service
│
├── controller
├── entity
├── repository
├── service
└── AccountServiceApplication.java
```

## Features Implemented
- Account Entity
- Account Repository
- Account Service
- Account Controller
- Basic Create Account API
